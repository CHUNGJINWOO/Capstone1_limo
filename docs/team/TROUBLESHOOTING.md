# 문제 해결과 중단 기준

사람이나 장비에 위험이 있거나 전원이 예기치 않게 꺼지면 현장 비상정지 절차를 우선하고 담당자에게 알린다. 원본 로그·bag을 보존하고 자동 재시도하지 않는다. 현재 센서·로봇 시험은 별도 승인 대상이다.

| 증상 | 근거와 현재 판단 | 대응 |
|---|---|---|
| Astra NULL 접근/종료 오류 | NULL 접근 수정 후보와 별도로 정적 파라미터 undeclare 오류 27건이 기록됨 | 후보 버전과 로그를 분리 보존. 오류를 숨기거나 후보를 임의 배포하지 않음 |
| CPU 급증 | OpenBLAS 다중 스레드 비용을 재현하고 필터 단일 스레드를 잠금 시험함. 전원 사고의 원인으로 확정되지 않음 | 승인된 프로세스 환경과 실제 스레드 수 확인. 전역 환경 변경 금지 |
| 점군 수신 저하 | 단독 A/B 1회에서 16 MiB SHM 설정이 수신을 개선. 수신은 발행과 다르고 payload 경로는 미확인 | 후보와 관측기/QoS/CPU를 함께 확인. timeout 완화 금지 |
| 비정상 시스템 정지 | 전원·충전 등 가설이 있으나 원인 미확정 | 충전 중 운용 금지, 재시도 중지, 증거와 Boot ID 보존 |
| TF 높이/장애물 누락 | LaserScan 높이가 costmap 하한 아래가 되는 구성 발견. 카메라 외부 파라미터는 실측 필요 | C2는 replay·시뮬 후보. 임의 TF 수정이나 주행 금지 |
| STALL_PENDING | 배포 Agent가 일시 상태에 FAILSAFE하는 시뮬 재현. 후보의 지연은 안전상 trade-off | 차단 우회하지 말고 담당자에게 기록 전달 |
| 지도 unknown이 free로 변함 | 저장 YAML의 `free_thresh: 0.25` 재로드에서 관측. 별도 시험의 `0.196`은 해당 데이터에서 unknown 보존 | 원본 보존, 재로드 후 영역 검증. 모든 지도에 숫자만 기계적으로 적용하지 않음 |
| SSH 블로킹 | 시험 세션 래퍼에서 대기 문제가 기록되고 수정 후보는 Mock 검증됨 | 실행 중 시험을 강제 종료하지 말고 담당자와 조율 |
| rosbag 기록 오류 | 일부 환경에서 지원하지 않는 인자 사용 및 기록 중단 사례가 있었음 | 현재 `ros2 bag record --help`와 종료·`ros2 bag info` 확인, 손상 bag 원본 보존 |

과거 시험의 성공만으로 현재 문제가 해결됐다고 간주하지 않는다. 각 대응은 승인된 별도 검증을 대신하지 않는다.
