# 팀원 빠른 시작: 현재는 준비와 상태 확인까지

**실차 구동·자동 맵핑·지도 클릭 이동은 차단 중이다.** 이 문서는 독립 운용을 위한 절차 틀과 현재 확인 가능한 단계다. 승인된 최신 배포본과 전체 동작 절차가 공개·검증되기 전에는 누락된 명령을 추측해 실행하지 않는다. 기존 운영 프로세스가 있다면 담당자에게 소유권을 확인한다.

1. **장비·전원:** 현장 담당자와 로봇, 주변 사람, 장애물·낙하 위험을 확인한다. 전원이나 네트워크 이상이면 기록하고 진행하지 않는다.
2. **충전:** 충전기를 분리하고 현장에서 전원 상태를 확인한다. 충전 중 운용은 금지한다.
3. **안전:** 물리적 모터 차단과 비상정지 수단을 직접 확인한다. 차단 해제·주행은 별도 승인 전 금지. 실제 바퀴 정지는 화면의 상태만으로 판단하지 않는다.
4. **연결:** 담당자가 제공한 인증 절차로 Tailscale에 연결하고 장비 이름과 접근 권한을 확인한다. 불명확하면 중단한다. SSH나 네트워크 재시도는 진행 중인 시험을 방해하지 않도록 담당자와 조율한다.
5. **환경:** [설치](SETUP.md)의 source·패키지 확인을 따른다. 기대한 패키지 경로가 아니면 드라이버를 실행하지 않는다.
6. **센서·TF:** 해당 현장 센서 실행이 별도 승인되고 담당자가 기동한 경우에만 `/scan`, `/imu`, `/odom`, Depth와 TF를 읽기 전용으로 확인한다. 예를 들어 `ros2 topic list`와 `ros2 topic hz /scan`을 사용한다. 토픽 부재·멈춤·오래된 데이터 또는 TF 불일치가 있으면 중단하고 담당자에게 보고한다. `hz`는 수신율이며 발행률의 증거가 아니다.
7. **시스템 기동:** 실차용 q13/C103 구성 및 설정은 Git에서 완전히 재현되지 않아 현재 제공할 검증된 단일 명령이 없다. 기존 담당자와 버전·해시를 확인하고 승인 전 기동하지 않는다.
8. **안전 상태:** Gate·Watchdog·Depth의 최신 상태, 통신·전원·물리 차단을 확인한다. READY 표시만으로 실제 안전이나 주행 허가를 추론하지 않는다. 이상 또는 미확인은 중단한다.
9. **자동 맵핑 START:** 현재 차단. 검증된 버전과 주행 안전 조건이 충족되고 현장 승인을 받은 이후에만 운영한다.
10. **PAUSE:** 향후 검증된 웹 운영에서는 PAUSE 요청 수락과 실제 정지를 구분한다. 목표 종료와 현장 바퀴 정지까지 확인한다. 상태가 UNKNOWN이거나 정지를 확인하지 못하면 재개하지 않는다.
11. **SAVE:** 정지 확인 후 저장. YAML/PGM 및 가능할 경우 posegraph/data를 확인하고 별도 환경에서 재로드해 unknown/free/occupied를 비교한다. `free_thresh` 문제를 [문제 해결](TROUBLESHOOTING.md)에서 확인한다. 실패한 지도는 운용용으로 등록하지 않는다.
12. **RESUME:** 지도 검증·보고 후 사용자가 명시적으로 승인할 때만 재개한다. 자동 재개하지 않는다. 현재 실차 재개는 차단.
13. **STOP:** 검증된 제어 경로로 중지 요청 후 목표 종료, 실제 정지, 해당 세션 소유 프로세스 종료를 확인한다. 다른 담당자의 프로세스를 종료하지 않는다.
14. **회수:** 운영자가 지정한 저장소에 지도·기록을 복사하고 원본과 해시를 비교한다. 대용량 bag과 사고 원본은 공개 Git에 올리지 않는다.
15. **전원 종료:** 현장 담당자가 모든 로봇 작업과 기록 종료를 확인한 뒤 장비 절차에 따라 정상 종료한다. 예기치 않은 정지라면 재시도하지 말고 증거를 보존한다.

## 웹 화면

현장 18190 서버와 Agent는 별도 데이터·인증 설정을 사용하며 이 저장소만으로 동일 환경을 재현하지 못한다. 담당자가 승인된 서버를 실행한 경우 로컬 브라우저에서 `http://127.0.0.1:18190/`으로 접속하고 승인된 계정·권한으로 상태를 확인한다. 토큰을 문서나 터미널 기록에 남기지 않는다. 서버 미접속·오래된 상태·거부 응답은 운영 중단 사유다. 실제 맵핑 및 목표 전송은 차단 조건이 해소되기 전 실행하지 않는다.

실제 실행 명령, 출력 예시, 배포·롤백의 완성된 런북은 담당자 검증과 누락 소스 공개 검토가 끝난 후 추가한다. [기존 격리 웹 계약](../../fleet_control/docs/WEB_MAPPING_20261119.md)은 과거 시험 기록이며 현재 장비 실행 지침이 아니다.
