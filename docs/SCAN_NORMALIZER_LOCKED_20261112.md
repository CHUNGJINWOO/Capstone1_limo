# 실차 LiDAR 정규화 모터 잠금 시험 (2026-11-12)

SLAM Toolbox에서 지도 갱신이 멈춘 현상을 조사하면서, LiDAR 스캔을 244빔으로 정규화한 경우와 원본을 사용하는 경우를 비교했다. 실차 모터 출력은 잠갔고 자동 탐색은 끈 상태에서 사람이 로봇을 밀었다. 이 시험은 자동 주행 검증이 아니다.

과거 관측에서 YDLidar의 회전별 빔 수는 주로 242~245개였고, Karto는 처리 중 다른 수의 빔이 도착하면 경고를 기록했다. 빔 수 변동이 지도 정체에 영향을 줬다는 **원인 후보**를 비교한 시험이다.

| 수동 이동 시험 | 정규화 OFF | 정규화 ON |
|---|---:|---:|
| wheel odom 이동 | 0.92 m | 1.06 m |
| 최대 속도 | 0.124 m/s | 0.062 m/s |
| SLAM 입력 빔 | 242개 3회, 244개 585회, 245개 114회 | 244개 702회 |
| 지도 known cells | 685 → 685 | 701 → 7,531 |
| Karto 빔 수 경고 | 5건 | 0건 |
| Gate | NORMAL, FAILSAFE 0 | NORMAL, FAILSAFE 0 |

각 조건의 유효 수동 이동은 70초 1회이며 속도가 달랐다. OFF의 첫 시도는 wheel odom 이동 0.0 m로 비교에서 제외했다. 따라서 관측은 원인 후보와 일치하지만 원인을 확정하거나 재현성을 증명하지는 않는다. 두 조건에서 `/cmd_vel` 메시지와 0이 아닌 잠금 출력은 관측되지 않았다.

별도의 정지 상태 각 25초 시험에서 ON의 `/scan_slam` 233개는 모두 244빔이었다. 같은 구간의 원본 `/scan` 관측은 241개로 차이가 났고 측정 시점 차이 가능성은 확인되지 않았다. 회전·긴 주행·루프 폐쇄·모터 구동 및 자동 탐색 결합은 시험하지 않았다. 정규화 구성은 SLAM 입력을 `/scan_slam`으로 바꾸며 Nav2와 Gate는 기존 `/scan`을 사용한다.

관련 기존 원인 조사와 검증 색인은 [SLAM scan 조사](../experiments/safety_gate_verification_20261110/slam_scan_fix_20261111/REPORT.md) 및 [VALIDATION.md](../VALIDATION.md)를 참조한다.
