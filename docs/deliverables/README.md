# 공개 최종 산출물

진도보고서와 발표자료는 최종본 한 개씩만 제공합니다. 파일은 [최종본 다운로드](https://github.com/CHUNGJINWOO/Capstone1_limo/releases/tag/midterm-final-2026-10-25)에 보관합니다.

| 자료 | 다운로드 | 범위 |
|---|---|---|
| 진도보고서 | 제출 최종본 확인 후 등록 | 초안이 포함된 기존 파일은 공개하지 않음 |
| 발표자료 | [PPTX 최종본](https://github.com/CHUNGJINWOO/Capstone1_limo/releases/download/midterm-final-2026-10-25/LIMO_midterm_presentation_final.pptx) | 중간진도 발표 17장, 주행·시뮬레이션 영상 3개 포함 |

학교 제출 원본과 공개용 사본은 별도로 보관합니다. 초안·중복 형식·주차별 보고용 문서·PPT 수정 검토 기록은 이 목록에 포함하지 않습니다. 발표자료는 LIMO 주행과 시뮬레이션, 확인 결과와 남은 검증·계획을 구분합니다. Windows PowerPoint의 직접 재생은 별도 환경 확인이 필요합니다.

시뮬레이션은 재현·원인 분석을 위해 [실행 코드와 환경 준비](../../experiments/simulation_benchmarks_20261024/README.md), [시험 결과와 판정 기준](../experiments/2026-10-24/README.md), [조사 기록](../SIMULATION_VERIFICATION_REPORT_2026-10-24.md)을 함께 보존합니다.
