# 2026-11-05 자동 맵핑 실패시험 계측 교정

## 목적과 변경 범위

Antigravity의 기존 실패시험에서 map 좌표와 Gazebo world 좌표 혼용, 반복 표본의 접촉 횟수 환산, 짧은 관측을 근거로 한 무한 루프 판정 문제가 있어 별도 복사본으로 시험 도구를 수정했다. 실제 자동 맵핑 코드는 `04_저속_진단_목표기록` 버전으로 고정했다. LIMO·USB 원본은 수정하지 않았다.

## 변경

- 물리 엔진 contact 센서로 접촉을 수집하고 바닥 접촉과 장애물 접촉을 분리했다.
- 원본 timestamp를 보존한 Gazebo world pose로 실제 이동 거리를 계산했다.
- 실행된 패키지 경로·import·소스 해시를 확인했다.
- 동적 박스를 실제 이동 확인 후 전방 경로점에 배치하고 실제 위치를 확인했다. 생성 전후 박스 표면 영역의 비용을 검사하고, SLAM 보정을 고려해 현재 좌표로 비교했다.
- Action 취소 수락과 최종 결과를 따로 확인했다. 다른 작업을 종료하는 일괄 프로세스 정리는 제거했다.
- 속도 double array 자료형 판정을 고치고, 최종 D에서 원시 global costmap도 보존했다.

## 실제 확인

- 시험 workspace의 `limo_mapping_interfaces`, `limo_auto_mapping` 빌드 완료. 기준 운영 소스 17개 동일, 원본 해시 목록 56개 변경 없음.
- 계측 계산 검사 6개 통과. 모델·월드는 관측용 추가분을 제외하고 원본 XML과 동일.
- 별도 벽 접촉 교정 후 실제 자동 맵핑 Action으로 A/B2/C/D 시험 수행. 전체 13개 실행에는 초기 교정 실패 두 번과 C 기동 실패 한 번도 포함한다.
- B2는 사실상 이동하지 못했으나 실패 횟수 3에 도달해 종료했고 부분 지도 네 파일을 저장했다. 무한 루프 주장은 뒷받침되지 않았다.
- C 유효 실행은 중심 비용 99에서 주행 목표를 보내지 않고 약 10초 뒤 오류 종료했다.
- A 세 실행에서 유리 접촉은 재현되지 않았다. 유리 안전성 통과로 기록하지 않았다.
- D는 박스 생성·제거와 실제 위치를 확인했으나 global costmap 반영 확인이 남았다. 완전 차단·재출발 통과로 기록하지 않았다.

## 한계와 다음 조사

실물 유리·책상 보강대 충돌, health lost 원인, wheel slip은 검증되지 않았다. 차체 형상과 LiDAR FOV도 실물과 다르다. 다음에는 B2의 목표 방향·조향 가능성·controller 반응과 D의 scan→TF→global/local costmap 반영을 조사한다. 이미 있는 재시도 제한을 새 기능으로 중복 추가하지 않는다.

시험 도구만 바꿨으므로 이번 작업 때문에 LIMO로 추가 전달할 파일은 없다. 기존 저속·진단 코드의 실물 검증 상태가 바뀐 것도 아니다.
