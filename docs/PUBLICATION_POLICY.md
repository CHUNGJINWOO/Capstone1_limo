# 저장소 공개 범위와 개인정보 보호

## 공개 범위

프로젝트 코드·설정·지도·기술 문서와 시뮬레이션의 시험 조건, 실패, 원인 분석, 개선 과정 및 결과를 공개한다. 구현·설정·검증·계획을 구분하고 검증 한계를 보존한다.

학교 제출용 진도보고서·팀별계획서·발표자료는 **최종본을 포함해 공개하지 않는다**. 초안·수정·검토 기록, 개인별 역할·기여도·평가 자료도 게시하지 않는다. 원본은 로컬에 보관한다. 대용량 영상·시계열 원본 로그·캡처·빌드 결과도 기본 추적 대상에서 제외한다.

## 개인정보 검토

학번, 개인 연락처·이메일, 서명, 비밀번호·토큰·개인키와 비공개 접속 정보를 커밋하지 않는다. 문서 본문뿐 아니라 이미지·문서 속성·노트·댓글·파일명과 Git 작성자·커미터 정보도 검토한다. 개인정보 보호가 필요한 커밋에는 GitHub noreply 이메일을 사용한다.

새 코드에는 개인 기기의 절대 경로를 넣지 않는다. 과거 실험의 환경 경로가 포함된 기록은 현재 환경의 실행 경로로 간주하지 않는다. 기록을 익명화할 때는 원본 보관, 변경 범위와 해시 검증 대상을 명시하며 실행 코드와 측정값을 임의로 변조하지 않는다. 제삼자 라이선스와 저작권 표시는 보존한다.

## 보관과 이력 관리

- 제출 원본과 복구 백업은 Git에서 제외된 `local-only/` 등 로컬 공간에 보관한다. 이 공간에도 민감정보가 있을 수 있으므로 공개·동기화하지 않는다.
- `.gitignore`는 이미 공개된 과거 커밋이나 릴리스 첨부를 제거하지 않는다. 이력 재작성은 사용자의 명시적 요청과 로컬 백업을 전제로 한다.
- 공개 이력을 교체한 뒤에는 새로 복제한다. 과거 브랜치·백업을 원격에 올리거나 기존 이력을 병합하지 않는다.
- 코드와 시뮬레이션 결과 파일을 보존하더라도 과거 Git 변경 이력은 복구 백업에만 남을 수 있다. 현재 파일의 존재가 모든 기능의 검증을 뜻하지 않는다.

공통 운영 기준은 [guidebook의 개인정보 보호 및 저장소 공개 지침](https://github.com/CHUNGJINWOO/guidebook/blob/main/docs/PRIVACY_AND_PUBLICATION.md)을 따른다. 이 문서는 이 프로젝트의 자료 공개 규칙이며 서비스의 개인정보 수집·처리를 설명하는 법적 고지 문서가 아니다.
