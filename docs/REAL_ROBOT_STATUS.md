# 검증 수준 요약: 실차(LIMO) · 시뮬레이션 · 오프라인 · 제안

기준일: 2026-11-11. 이 문서는 "무엇이 어디까지 확인되었는가"만 정리한다. 파일이 저장소에 있다는 사실이 그 기능의 검증을 뜻하지 않는다(`AGENTS.md` §5.2).

범례: **실차 검증** = 물리 LIMO에서 실행해 기록을 남김 / **시뮬레이션 검증** = Gazebo Fortress에서만 확인 / **오프라인 검증** = 저장된 실차 bag 재생 등 로봇 없이 확인 / **제안** = 설계·diff만 있고 로봇에 적용하지 않음 / **미검증** = 실행하지 않음.

## 2. 실차 시험의 공통 조건
- 모터 구동은 사용자 입회·전원 스위치 대기 상태에서 단계별 승인 후에만 했다. 단계 통과가 다음 단계의 승인을 뜻하지 않았다.
- 정지는 소프트웨어 게이트와 MCU 타임아웃에 의존했다. 물리 E-Stop은 별도 검증하지 않았다.
- LiDAR는 전방 약 220°만 보며 후방 약 140°는 스캔되지 않는다. 어둡고 낮은 물체(검은 스티로폼)는 LiDAR에 거의 잡히지 않았다. 따라서 LiDAR 기반 정지·회피 판단은 그런 물체를 모른다.
- 지상 시험 중 바닥 마찰, 실제 이동 거리·회전각은 줄자·각도기로 대부분 실측하지 않았다(F4/휠 odom 비교 값만 있음).

## 3. 이번 정리 단계에서 로봇으로 확인하지 않은 것
정리 브랜치(`cleanup/*`)의 변경은 LIMO가 꺼진 상태에서 만들었다. 다음은 **실차에서 실행해 확인하지 않았다**: 분리한 실차 YAML 두 개(`integrated_nav2_real_depth_params.yaml`, `integrated_explore_real_params.yaml`)로 launch를 올리는 것, `complementary_filter_node` 등 추가 실행 파일의 실차 실행, 이동한 launch의 모터 잠금 동작. 확인한 것은 문법·YAML/XML 파싱·launch 인자 평가·빌드까지다.
