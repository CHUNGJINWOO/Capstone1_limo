## 2. `live-api.jpg`: exclusion and a finding about history
- Excluded from the G1 file list; the original stays on disk and is in both snapshots (SHA256 `b663f8fe…`); nothing was deleted.
- **Finding:** `feat/fleet-control-unified` already tracks this file (a candidate "identical to unified"). That branch is **not on any remote**, and exactly 2 of its commits (`419e7987`, `ed53d81b`) exist only locally; `ed53d81b` is the one that adds the image. A branch built on top of unified would carry the image in its history even if the tip removes it, and pushing it would publish it. Therefore the parent for G1 is **not** unified (§5).
- Patch P5 adds an ignore rule for the file to `fleet_control/.gitignore`, so a later `git add -A` cannot pick it up.
