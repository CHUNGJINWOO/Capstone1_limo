Map-centred Workspace · 승인 전 디자인 제안

이 자료는 운영 UI와 분리한 HTML 시안의 실제 Chromium 캡처입니다. 기존 대시보드는 수정하지 않았습니다. 지도·로봇·이벤트는 격리 서버에서 GET으로 읽은 합성 표본이며, 명령·센서·임무 상태를 생성하지 않았습니다. 현재 임무는 실제 조회 결과 0건입니다.

2. 공식 레퍼런스와 판단

RMF Workspace 문서는 MicroApp 간 이벤트로 선택을 연결하며 Task 행을 선택하면 해당 로봇으로 지도를 이동시키는 예를 설명합니다. 이번 제안은 이 연결 구조를 기존 Vanilla UI에서 구현하는 설계입니다. React/RMF framework를 도입하는 제안이 아닙니다. 문서의 examples 링크는 조회 실패로 기록하며 로그인된 RMF 배포 환경을 검증했다고 주장하지 않습니다.

5. 검증 범위와 승인 대상

  • PASS: 독립 HTML 시안 6장 실제 Chromium 1920×1080, 문서 가로/세로 overflow 없음, JS 오류 없음.
  • PASS: 시안 로봇 선택 → 지도/Inspector, Operation 명령 Drawer 열기, 두 테마.
  • SKIP: 운영 UI 적용 및 API 명령·임무·Lease·안전 회귀. 승인 후 구현 단계에서 실행.
  • 미구현 시안 상호작용: Task 선택 연동(현재 표본 0건), 예외 스트립의 Fault/Offline 조건 변화, Safety Drawer 상세, Building, 지도/센서 소스 설정. 이들은 설계 의도이며 검증 완료가 아님.
  • 확정 요청: 지도 중심 3열 Workspace, 34px 전역 예외 스트립, 선택 공유 모델, 접힌 Goal Drawer, Spatial 3그룹 도구 구조. 승인 전 기존 runtime 파일 변경 없음.
