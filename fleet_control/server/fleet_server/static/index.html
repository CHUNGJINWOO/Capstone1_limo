      운영 제어 · 지도 관리 · 프로파일 (설계 준비)
      
백엔드 API 미구현 · 비활성

      

      자세한 안내
      향후 Fleet Server Operation Manager 및 Map Registry 연동 시 활성화될 기능입니다. 현재 백엔드 API가 없어 모든 원격 조작 버튼은 비활성화되어 있습니다.
      

      

      1. 자동 맵핑 제어 (SLAM / Explore)
      

      



      

      필요 API: Operation Manager — 현재 operation_mode 읽기 보고만 존재하며 원격 모드 전환 API는 미구현입니다.
      

      

      

      2. 지도 저장 및 불러오기 (Map Registry)
      

      




      

      현재는 Agent가 발행하는 `/map` PNG 스냅샷 조회(GET /api/v1/robots/{id}/map.png)만 지원됩니다.
      

      

      

      3. 안전한 알고리즘 프로파일 변경
      

      



      

      주행 중 프로파일 변경 금지: 정지·모터 잠금·관리자 인증·버전 해시 검증 API 구축 후 연동 예정입니다.
      

      

      

      

      자세한 안내
      건물·층·버전 선택은 관제 지도 상단에서 변경합니다. 저장 지도는 미리보기 전용입니다.
      운영 매뉴얼
      1. 로봇과 연결 상태, Gate 및 지도 검증 상태를 확인합니다.
      2. 임무 · Lease에서 제어권을 획득한 뒤 라이브 지도에서 목표를 선택합니다.
      3. 임무 생성은 서버 검증 후 처리됩니다. 취소 요청은 정지 완료를 의미하지 않습니다.
      4. 복구는 운영 · 복구 화면에서 admin 권한과 현장 증거로 진행합니다.
      5. 물리 E-Stop과 실차 안전 확인은 현장 작업자가 수행합니다.
